# Taskly

Taskly is a clean, modern, offline-first To-Do List web application built with vanilla HTML, CSS, and JavaScript.

## Features

- **Local Storage Persistence**: Works without a database or backend; tasks remain saved across page reloads.
- **Task Management**: Add, view, edit, complete, and delete tasks (with confirmation prompt).
- **Due Dates & Times**: Optional due date and time for each task.
- **Reminders**: In-browser notifications and toasts for upcoming task due times.
- **Priority Levels**: Tag tasks with Low, Medium, or High priority with visual badges and border accents.
- **Search & Filtering**: Search in real-time with highlighted text and filter by All, Pending, or Done status.
- **Live Statistics & Progress Bar**: Real-time counter of total, pending, completed, and overdue tasks, plus completion progress.
- **Responsive Layout**: Designed and styled for desktop, tablet (iPad), and mobile devices.

## Getting Started

Open [`index.html`](index.html) in any modern browser. No build steps or server dependencies are required.
